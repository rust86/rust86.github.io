Локальный инструмент для подготовки документов к работе с ИИ.

## Возможности

- DOCX, XLSX, PPTX, PDF и другие форматы → Markdown
- Пакетная загрузка файлов и папок
- Подсчёт токенов до и после конвертации
- Чанкинг документов для RAG
- Экспорт JSONL с metadata
- Профили для RAG, Cursor, ChatGPT и Claude
- Локальная обработка файлов в браузере
- OCR изображений и скриншотов
